# Aura AI Workspace

ROLE: Act as an expert full-stack AI developer, prompt engineer, UI/UX designer and responsible AI specialist.

OBJECTIVE: Build a modern, professional, responsive AI Workplace Assistant SaaS app for students, employees, managers, entrepreneurs and professionals. It must use AI intentionally to solve workplace productivity problems and feel like a real product, not a basic chatbot.

AI FEATURES

1. Smart Email Generator

Inputs: recipient, purpose, context/key points and tone.

Tones: Formal, Friendly, Persuasive.

Generate professional editable emails with Copy and Regenerate.

2. Meeting Notes Summarizer

Accept long meeting notes.

Generate: Summary, Key Discussion Points, Decisions, Action Items, Deadlines and Open Questions.

Include Copy and Regenerate.

3. AI Task Planner/Scheduler

Accept tasks, deadlines, urgency and importance.

Prioritize tasks and create daily/weekly schedules.

Display an organized schedule.

DASHBOARD & NAVIGATION

Create a professional dashboard with branding, description, feature cards, quick actions, productivity overview and recent activity/generated outputs.

Responsive sidebar: Dashboard | Email Generator | Meeting Summarizer | Task Planner | Settings

Support desktop, tablet and mobile with mobile-friendly navigation.

FEATURE UI

Each feature needs clear instructions, forms/options, Generate button, loading state, structured AI output, Copy/Edit/Regenerate actions, and polished empty/success/error states.

PROMPT ENGINEERING

Create a dedicated structured prompt for each AI feature using: Role, Objective, Context, User Input, Requirements/Constraints, Tone, Exact Output Format and Responsible AI instructions. Use structured/schema-based outputs where appropriate and avoid vague prompts.

UI/UX

Use a clean, modern productivity-app design with strong typography, spacing, cards, accessible controls, clear hierarchy, whitespace, subtle interactions and fully responsive layouts.

RESPONSIBLE AI

Display a disclaimer stating that AI may make errors, important information must be reviewed, outputs are not automatically verified, users should avoid confidential/private/sensitive information, and users remain responsible for decisions.

ERROR HANDLING

Handle empty/invalid/long inputs, AI/API errors, network failures and unexpected responses with clear, friendly messages.

INNOVATION

Add Saved Outputs/Recent Activity or another useful feature such as cross-feature workflows, productivity insights, favorite prompts or export.

ARCHITECTURE & DEVELOPMENT

Keep UI, AI prompts/services, validation and data modular for future features. Build all three AI features, dashboard/navigation, structured prompts/schemas, responsive components, AI functionality, validation, responsible AI messaging and error handling. Test realistic examples and desktop/mobile layouts, then polish the UI/UX.

FINAL

All three features must be fully functional AI workflows, not mockups. Deliver a polished professional project demonstrating practical AI, strong prompt engineering, innovation, responsible AI, functionality and excellent responsive UX.
